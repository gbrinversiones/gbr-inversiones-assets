# ON del screener: suplementos y avisos de resultados

Documentos oficiales de la CNV bajados desde el visor público (aif2.cnv.gov.ar) para cruzar cupón, amortización, emisión y vencimiento de cada ON que muestra gbr-landing. Carpeta por ticker. `terminos_ons.csv` resume el cruce.

Excepciones: YM44O y PNRCO ya tienen su suplemento correcto. YMCXO usa el suplemento de la Clase XXXI (la CNV tiene otro de las Clases XXXII y XXXIII para el mismo emisor). El aviso de YMCXO es el complementario de la reapertura (OCR no hecho: se leyó como imagen).
